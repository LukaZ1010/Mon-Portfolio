5000 Hanzi (Progressive Web App)

Conception et développement d'une Progressive Web App (PWA) conçue pour la mémorisation et la recherche des 5000 caractères chinois les plus fréquents.

Ce projet consistait à créer une application web légère et autonome capable de fonctionner sans aucune connexion Internet (offline) et installable sur l'écran d'accueil d'un smartphone pour proposer une expérience similaire à celle d'une application native.

Technologies Progressive Web App

  • Service Worker (sw.js) : Fichier JavaScript exécuté en arrière-plan. Il intercepte les requêtes réseau et applique une stratégie de mise en cache locale via la Cache API, assurant un chargement immédiat et un accès hors-ligne.
  • Web App Manifest (manifest.json) : Fichier de métadonnées spécifiant l'affichage autonome (standalone), les icônes de l'application, et la couleur de thème (`#d32f2f`) pour permettre son installation native.

Intégration & Performance

  • Base de Données Locale : Structuration optimisée de l'ensemble des 5000 caractères, de leur Pinyin (prononciation) et de leurs définitions directement au sein du code pour une recherche instantanée sans API distante.
  • Interface Responsive : Conception Mobile-First utilisant un design fluide et ultra-réactif pour un confort de lecture maximal sur smartphone.

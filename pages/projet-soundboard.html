Luka Soundboard

Application bureau Windows permettant l'injection de fichiers audio et la redirection de flux applicatifs vers la sortie microphone.

Conçue pour les streamers et les créateurs de contenu, cette application permet de centraliser la gestion d'effets sonores, de les jouer à la volée, et de capturer à chaud le flux audio d'autres logiciels (navigateur, Spotify) pour les mixer en temps réel avec le micro.

Fonctionnalités Clés

  • Bibliothèque de sons : Gestion complète permettant d'importer, de nommer et d'attribuer des raccourcis clavier à des clips audio (MP3, WAV).
  • Injection Micro : Redirection directe du son joué vers l'entrée micro des logiciels tiers (Discord, Microsoft Teams, jeux vidéo).
  • Routage d'application : Capture dynamique de l'audio d'une application spécifique pour la diffuser dans le flux micro.

Optimisation & Architecture

  • API Windows WASAPI : Utilisation du protocole de bas niveau WASAPI de Windows pour assurer une latence de traitement quasi nulle.
  • C++ & Qt6 : Développement compilé et interface fluide sous Qt, minimisant la charge CPU pour ne pas pénaliser les performances des jeux ou du stream.

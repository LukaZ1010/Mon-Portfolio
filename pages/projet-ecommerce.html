Site E-Commerce PHP complet (MVC)

Développement complet d'une plateforme de commerce électronique fonctionnelle, structurée selon le modèle MVC et écrite en PHP natif sans framework.

L'objectif de ce projet était de concevoir une application web robuste en mettant en pratique les concepts de Programmation Orientée Objet (POO) en PHP, la modélisation de bases de données relationnelles SQL et la sécurisation des sessions et des données utilisateurs.

Architecture Logicielle MVC

  • Modèle (Model) : Gère les interactions et la communication avec la base de données SQL. Utilise des requêtes préparées PDO pour sécuriser les données et éviter toute injection SQL.
  • Vue (View) : Reçoit les variables formatées issues du contrôleur et s'occupe du rendu visuel de la page en HTML5 et CSS3.
  • Contrôleur (Controller) : Intercepte les requêtes HTTP envoyées par l'utilisateur, traite la logique métier et choisit la vue à afficher.

Fonctionnalités Clés Implémentées

  • Gestion des Sessions : Inscription et authentification sécurisées. Les mots de passe sont hachés en base de données à l'aide de l'algorithme `bcrypt` (via `password_hash`).
  • Catalogue Dynamique & Panier : Chargement automatique des produits depuis MySQL. Gestion d'un panier d'achat dynamique stocké dans la session de l'utilisateur.
  • Validation & Sécurisation : Nettoyage rigoureux de toutes les entrées utilisateurs (formulaires) afin de prévenir les failles XSS et les injections SQL.
